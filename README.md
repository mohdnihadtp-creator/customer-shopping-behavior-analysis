# 🛍️ Customer Shopping Behavior Analysis

## 📌 Project Overview

This project analyzes the shopping behavior of **3,900 retail customers** to understand purchasing patterns, customer segments, product performance, subscription behavior, discounts, shipping preferences, and revenue contribution.

The project follows an end-to-end data analytics workflow using:

- 🐍 Python & Pandas for data cleaning and preparation
- 🗄️ MySQL for SQL-based business analysis
- 📊 Power BI for interactive visualization and dashboard creation

The final outcome is an interactive Power BI dashboard supported by SQL-based business insights.

---

## 🎯 Business Problem

The objective of this project is to analyze customer shopping behavior and answer important business questions such as:

- Which customer groups generate the most revenue?
- Do subscribed customers spend more?
- How do discounts affect purchasing behavior?
- Which products receive the highest ratings?
- Which products rely most heavily on discounts?
- What are the most purchased products in each category?
- How does shipping type relate to purchase amount?
- How many customers are New, Returning, and Loyal?
- Are repeat buyers more likely to subscribe?
- Which age groups contribute the most revenue?

---

## 📊 Dataset

The dataset contains **3,900 customer purchase records** and **18 columns**.

### Main Data Categories

**Customer Information**
- Customer ID
- Age
- Gender
- Location
- Subscription Status
- Previous Purchases
- Frequency of Purchases

**Product Information**
- Item Purchased
- Category
- Size
- Color
- Season

**Transaction Information**
- Purchase Amount
- Review Rating
- Shipping Type
- Discount Applied
- Promo Code Used
- Payment Method
